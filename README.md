# Outseta OAuth & OpenID Connect SSO for WordPress

Integrate secure Single Sign-On (SSO) between WordPress and Outseta using the miniOrange WordPress OAuth & OpenID Connect Single Sign-On plugin.

This setup allows users to log in to your WordPress site using their Outseta credentials while supporting advanced features such as:

- OAuth 2.0 and OpenID Connect authentication
- User Attribute Mapping
- Role Mapping
- Secure SSO login flow
- Custom OAuth provider configuration

---

## Overview

The miniOrange WordPress OAuth & OpenID Connect Single Sign-On (SSO) plugin enables WordPress authentication using Outseta as the OAuth/OpenID provider.

After completing the configuration:

- Users can authenticate via Outseta
- WordPress automatically creates or updates users
- SSO login is available directly from the WordPress login page

---

# Prerequisites

Before starting, ensure you have:

- A working WordPress site
- Admin access to WordPress
- An Outseta account with developer access
- miniOrange OAuth & OpenID Connect SSO plugin installed

---

# Plugin Installation

## Install from WordPress Dashboard

1. Log in to WordPress Admin Dashboard
2. Navigate to:

```text
Plugins → Add New
```

3. Search for:

```text
WordPress OAuth Single Sign-On (SSO)
```

4. Install and activate the plugin

---

# Step 1: Configure Outseta as OAuth Provider

## Create Application in Outseta

1. Log in to your Outseta developer account
2. Click **Add Application**
3. Enter the application name
4. Save the application

## Configure Redirect URL

1. Copy the **Callback/Redirect URL** from the WordPress OAuth plugin
2. Paste it into the Outseta application configuration
3. Save changes

## Copy Credentials

Copy the following from Outseta:

- Client ID
- Client Secret

You will need these in WordPress configuration.

---

# Step 2: Configure WordPress as OAuth Client

## Add OAuth Application

1. Go to:

```text
Configure OAuth → Add New Application
```

2. Select:

```text
Custom OAuth 2.0 App
```

3. Copy the generated Callback URL
4. Click **Next**

---

## OAuth Endpoints Configuration

Replace `<your-site>` with your actual Outseta domain.

| Setting | Value |
|---|---|
| Scope | `openid profile email` |
| Authorization Endpoint | `https://<your-site>.outseta.com/connect/authorize` |
| Access Token Endpoint | `https://<your-site>.outseta.com/connect/token` |
| User Info Endpoint | `https://<your-site>.outseta.com/connect/userinfo` |

---

## Enter Client Credentials

Fill in:

- Client ID
- Client Secret

Set Scope as:

```text
openid profile email
```

Click:

```text
Next → Finish
```

Your WordPress OAuth Client configuration is now complete.

---

# Step 3: User Attribute Mapping

Attribute Mapping is required for successful SSO login.

## Configure Mapping

1. Navigate to:

```text
Configure OAuth → Test Configuration
```

2. Verify the following attributes are returned:

- Username
- Email
- First Name
- Last Name

3. Go to:

```text
Attribute / Role Mapping
```

4. Select appropriate Username attribute
5. Save configuration

---

# Step 4: Enable SSO Login Button

## WordPress 5.9 and Above

1. Enable:

```text
Show on login page
```

2. Open WordPress login page:

```text
https://<your-wordpress-domain>/wp-login.php
```

3. You should now see the Outseta SSO login button

# Troubleshooting

## Common Issues

### Missing User Attributes

If Email or Username is missing:

- Verify scopes include:

```text
openid profile email
```

- Check Outseta user profile permissions

---

### Redirect URI Mismatch

Ensure the callback URL in Outseta exactly matches the one generated by the WordPress plugin.

---

### Login Loop or Authentication Failure

Verify:

- Client ID
- Client Secret
- OAuth endpoints
- SSL/HTTPS configuration
